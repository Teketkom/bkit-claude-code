# Русские триггеры агентов (RU Agent Triggers)

> Расширение мультиязычной поддержки ROSSI для русского языка.
> Расширяет мультиязычную поддержку ROSSI до 9 языков (EN, KO, JA, ZH, ES, FR, DE, IT, RU).

## Расширение SUPPORTED_LANGUAGES

В файле `lib/intent/language.js`:

```javascript
// Было:
const SUPPORTED_LANGUAGES = ['en', 'ko', 'ja', 'zh', 'es', 'fr', 'de', 'it'];

// Стало:
const SUPPORTED_LANGUAGES = ['en', 'ko', 'ja', 'zh', 'es', 'fr', 'de', 'it', 'ru'];
```

## Интеграция в description агентов

Пример добавления RU-триггеров в frontmatter агента `cto-lead.md`:

```yaml
description: |
  ...
  Triggers: team, project lead, CTO, ...
  команда, лид проекта, руководитель, CTO, координация команды
```
